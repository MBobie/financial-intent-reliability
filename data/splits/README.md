# Split identifiers

Place files here that allow the fixed experimental split to be reconstructed.

Recommended files:

```text
hilbot_train_ids.csv
hilbot_test_ids.csv
hilbot_validation_ids.csv
```

The primary Hilbot-FI split used in the study is:

- train: 1,220
- test: 305
- neural validation subset drawn from training: 183
- remaining neural training subset: 1,037

The split and validation indices should remain frozen.
