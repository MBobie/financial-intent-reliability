# Data Statement

## Primary corpus

The primary study uses Hilbot-FI, an English financial intent classification corpus containing 1,525 utterances across 33 intents.

The repository should not redistribute the raw corpus unless the authors have verified the legal and licensing basis for doing so.

For reproducibility, provide where permitted:

- split identifiers;
- changed-query perturbation files;
- audit labels;
- derived result tables;
- instructions for obtaining the original dataset.

## External corpus

BANKING77 is used for targeted external validation using its official train/test split. Link users to the official source rather than duplicating the dataset unnecessarily.

## Language and scope

Both corpora are English-language financial/banking intent datasets. The study does not establish multilingual, dialectal, code-switching, speech-recognition, or production-traffic performance.

## Privacy

No repository file should contain credentials, personal access tokens, private user conversations, or personally identifying information that is not already lawfully public and appropriate for redistribution.
